Цель проекта заключается в разработке и обучении агента с подкреплением (RL-агента), способного оптимизировать энергетическое состояние графа, используя известную физическую модель Изинга. Эта модель представляет собой классическую задачу комбинаторной оптимизации, применяемую в различных областях физики и машинного обучения.

Данные решения являются решениями для AIIJC: отборочный этап и полуфинал,  на отборочном этапе графы состоят из 50 вершин, на полуфинале из 100 вершин.

Сама задача формулируется следующим образом: у нас есть граф, который задан матрицей. Матрица симметрична, пересечение $i$ строки и $j$ столбца  - вес ребра между вершинами $i$ и $j$, вес принимает значения ${-1,0,1}$. Обозначим это $J_{ij}$. Есть также спины s - значения в вершинах принадлежащие ${-1,1}$. Нам надо меняя спины, максимизировать энергию системы $\sum_{i,j} J_{ij}\cdot s_i \cdot s_j$

Наша цель - обучить RL агента, который пошагово меняет спины и максимизирует энергию
